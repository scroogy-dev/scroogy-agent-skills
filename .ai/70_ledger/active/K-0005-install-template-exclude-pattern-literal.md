# K-0005: install-skills 설치 결과 템플릿이 배포 제외 패턴 리터럴을 복제한다

- **유형**: 기술부채
- **등재일**: 2026-08-08
- **출처**: 이슈 #84 / audit 발견 F-4
- **위험도**: 낮음(LOW)
- **수용 사유**: 현재 템플릿의 리터럴은 5단계 패턴과 일치해 실해가 없고, 불일치는 5단계 제외 패턴이 변경될 때만 발현한다. 5단계에는 이미 "단일 출처" 명시가 있어 패턴 변경 작업자가 참조처를 함께 훑을 단서가 존재한다.
- **재검토 조건**: `install-skills/SKILL.md` 설치 절차 5단계의 배포 제외 패턴(`--exclude`)을 변경할 때, 또는 설치 결과 보고의 제외 패턴 표기가 실제 배포와 다른 사례가 관측될 때
- **상태**: 수용

## 내용

`install-skills/templates/install-result-template.md`의 `적용 옵션 내역` 중 `배포 제외 패턴` 행이 `tests/`, `*.test.*` 리터럴을 직접 보유한다. 제외 패턴의 단일 출처는 `install-skills/SKILL.md` 설치 절차 5단계인데 템플릿이 같은 값을 복제해, 5단계 패턴 변경 시 템플릿 갱신을 빠뜨리면 실제 배포와 사용자 보고가 달라진다.
