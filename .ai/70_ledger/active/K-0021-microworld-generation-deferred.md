# K-0021: 변경 동작을 조작해 볼 축소 모형(마이크로월드) 생성 기능이 없다

- **유형**: 기술부채
- **등재일**: 2026-11-01
- **출처**: 이슈 #130 (spec 제외 보류 항목)
- **위험도**: 낮음(LOW)
- **수용 사유**: 변경마다 조작 가능한 축소 모형을 만드는 비용이 크고, 어떤 변경에 필요한지 기준도 없다. 완료의 정의 연결(이슈 #130)과 독립된 기능이라 별도 스킬 후보로 둔다.
- **재검토 조건**: 서술·호출 흐름·시퀀스 다이어그램·전후 예시만으로 변경 동작을 이해하기 어려웠던 PR 사례가 반복될 때, 또는 마이크로월드 생성을 스킬로 만들기로 결정할 때
- **상태**: 수용

## 내용

리뷰어가 변경 동작을 직접 조작해 확인할 축소 모형(마이크로월드)을 만드는 기능이 어느 스킬에도 없다. PR 이해는 git-pr 본문의 서술, 호출 흐름 트리, 시퀀스 다이어그램, 전후 예시에 의존한다.

## 재검토 이력

없음

- **영향**: 기능 저하. 리뷰는 그대로 진행되고, 동작이 복잡한 변경에서 이해를 돕는 수단이 하나 적을 뿐이다.

- **채택하지 않은 대안**: 이슈 #130에서 PR 본문 구성과 함께 마이크로월드를 생성하는 안. 작성 비용이 커서 보류했다.
