# K-0034: git-review 리뷰 결과를 PR에 게시하는 절차가 없다

- **유형**: 기술부채
- **등재일**: 2026-11-22
- **출처**: 이슈 #142 (spec 제외 보류 항목)
- **위험도**: 중간(MEDIUM)
- **수용 사유**: 게시 형식(댓글 하나로 올릴지 줄 단위 리뷰 코멘트로 올릴지, 어느 섹션을 올릴지)이 정해지지 않았다. 프롬프트로 게시해 본 뒤 형식이 잡히면 판단하기로 했고, 형식 없이 절차를 만들면 쓰지 않는 단계가 남는다. 결과 파일을 프롬프트로 PR에 게시하는 것은 지금도 할 수 있다.
- **재검토 조건**: 프롬프트로 PR에 게시한 리뷰 결과의 형식이 여러 번 같게 잡혔을 때, 또는 git-review `## 결과 기록 형식`이나 결과 템플릿의 구조를 바꿀 때
- **상태**: 수용

## 내용

git-review는 리뷰 결과를 `.ai/99_workspace/temp_review_result.md`에만 쓰고 PR에 게시하는 절차가 없다. PR 모드 리뷰 결과를 PR 작성자와 다른 리뷰어에게 보이려면 사용자가 따로 프롬프트로 게시해야 한다.

## 재검토 이력

없음
