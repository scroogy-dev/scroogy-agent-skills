# K-0017: ADR을 superseded/로 옮긴 뒤 끊긴 링크를 결정적 헬퍼로 검사하지 않는다

- **유형**: 기술부채
- **등재일**: 2026-10-25
- **출처**: 이슈 #121 (spec 제외 보류 항목)
- **위험도**: 낮음(LOW)
- **수용 사유**: 링크 갱신 규칙이 스킬 밖(ADR index `## 수명 주기`)에 있어 헬퍼를 둘 스킬이 정해지지 않았다. `superseded/` 이동 사례가 아직 0건이고, 규칙은 옮긴 ADR 파일명으로 `.ai/`를 검색해 옛 경로가 남지 않았는지 확인하게 한다.
- **재검토 조건**: 첫 `superseded/` 이동에서 링크 갱신 누락이 관측될 때, 또는 ADR index `## 수명 주기`의 들어오는 링크 갱신 행을 실질적으로 바꿀 때
- **상태**: 수용

## 내용

ADR을 `superseded/`로 옮길 때 들어오는 링크 갱신은 ADR index 규칙과 파일명 검색으로만 확인한다. 원장의 `check-ledger-links.sh`처럼 끊긴 링크를 결정적으로 세는 헬퍼가 없다. 검색 결과를 잘못 읽으면 끊긴 링크가 남는다.

## 재검토 이력

없음

- **영향**: 기능 저하. 끊긴 링크는 문서 탐색을 막지만 스킬 동작은 바꾸지 않는다.
- **발생확률**: 특수 조건·엣지. `superseded/` 이동이 일어나고 검색 결과 확인까지 빠뜨려야 발현한다.
- **채택하지 않은 대안**: `check-ledger-links.sh`를 ADR 링크까지 넓히는 안. 원장 항목 파일명만 판정하는 헬퍼이고, 사본 3개가 ADR 이동 절차가 없는 스킬에 있어 배제했다(ADR 0022 `## 대안`).
- 2026-10-25 이슈 #121 완료 시(`--clear` 4단계) 보류 항목 등재 질의에서 등재했다.
