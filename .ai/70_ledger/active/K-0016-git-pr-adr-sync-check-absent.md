# K-0016: git-pr 문서 동기화 점검이 변경과 ADR 결정의 어긋남을 대조하지 않는다

- **유형**: 기술부채
- **등재일**: 2026-10-25
- **출처**: 이슈 #121 (spec 제외 보류 항목)
- **위험도**: 낮음(LOW)
- **수용 사유**: 변경이 ADR 결정과 어긋나는지는 의미 판단이라, 낡은 문서를 diff 신호로 찾는 점검 표의 다른 행과 성격이 다르다. 겪은 사례가 없고, issue-audit·git-review가 ADR index와 `context-loading.md`를 거쳐 ADR 정합성을 이미 대조한다.
- **재검토 조건**: ADR 결정과 어긋난 변경이 머지된 사례 관측 시, 또는 git-pr 문서 동기화 점검 표의 행을 실질적으로 바꿀 때
- **상태**: 수용

## 내용

git-pr 문서 동기화 점검 표는 README·AI-CONTEXT·코드 색인·원장이 낡았는지만 diff 신호로 본다. 변경이 `.ai/50_adr/active/`의 결정과 어긋나도 이 점검은 권고하지 않는다. 리뷰나 감사를 거치지 않은 PR에서는 어긋난 변경이 그대로 머지될 수 있다.

## 재검토 이력

없음

<summary>근거·배경 펼치기</summary>

- **영향**: 기능 저하. 결정과 어긋난 변경이 머지되면 ADR이 실제 동작을 설명하지 못한다.
- **발생확률**: 특수 조건·엣지. issue-work 흐름의 PR은 교차모델 감사가 ADR 정합성을 대조하므로, 감사와 리뷰를 모두 거치지 않은 PR에서 발현한다.
- **채택하지 않은 대안**: 이슈 #121에서 git-pr 문서 동기화 점검 표에 ADR 대조 행을 더하는 안. 겪은 사례가 없어 보류했다.
- 2026-10-25 이슈 #121 완료 시(`--clear` 4단계) 보류 항목 등재 질의에서 등재했다.
