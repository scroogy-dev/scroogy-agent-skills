# K-0045: 사람 확인(`[ND]`)만 있는 이슈는 전부 확인해도 완료 확인이 `다음 회차`를 권장한다

- **유형**: known issue
- **등재일**: 2026-11-23
- **출처**: 이슈 #145 (계획 감사 2차 F-16)
- **위험도**: 낮음(LOW)
- **수용 사유**: 완료 확인의 권장 기준 1("1단계 상태가 충족")은 이슈 #145 AC11의 문장이다. 판정 불가를 받아들이게 고치면 변경 통제의 완화라 이슈 본문 갱신과 재승인이 필요하다. 루프를 나갈지는 사용자가 정하고, 전부 확인한 이슈는 남은 AC가 없어 `마무리`를 골라도 추가 질의가 생기지 않는다.
- **재검토 조건**: `[ND]` 줄만 있는 이슈를 새 구조로 진행해 권장이 사용자 판단과 어긋난 사례가 나올 때, 또는 완료 확인의 권장 기준을 바꿀 때
- **상태**: 수용

## 내용

plan `테스트 계획`의 모든 AC가 `[ND]` 줄만 가진 이슈는 issue-audit 1단계 항목이 전부 판정 불가(N/A)라 1단계 상태도 판정 불가다. issue-work 완료 확인은 권장 기준 1에 닿지 않아, 사용자가 모든 줄을 확인한 뒤에도 `다음 회차`를 권장한다. 같은 입력으로 감사를 다시 받아도 권장은 바뀌지 않는다.
