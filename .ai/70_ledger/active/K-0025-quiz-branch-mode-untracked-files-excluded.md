# K-0025: git-review-quiz 브랜치 모드 diff가 미추적 새 파일을 빼는데 SKILL.md는 작업 트리 변경을 포함한다고 적는다

- **유형**: known issue
- **등재일**: 2026-11-03
- **출처**: 이슈 #132 Task 6 실제 실행 점검
- **위험도**: 중간(MEDIUM)
- **수용 사유**: 이슈 #132 완료의 정의(AC1~AC21)에 없는 결과라 변경 통제상 확장이며, 사용자가 원장 등재를 골랐다(2026-11-03). 새 파일을 커밋한 뒤 실행하면 퀴즈 입력에 들어가므로 우회할 수 있다. 미추적 파일을 넣으려면 `git add -N`(인덱스 변경)과 파일별 `git diff --no-index` 중 하나를 골라야 하고, 무시 규칙·대용량 파일 처리까지 정해야 해서 별도 설계가 필요하다.
- **재검토 조건**: 브랜치 모드에서 새 파일이 빠진 퀴즈가 다시 만들어진 사례 관측 시, 또는 git-review-quiz 2단계 diff 수집 절차(브랜치 모드 명령·작업 트리 안내 문장) 변경 시
- **상태**: 수용

## 내용

git-review-quiz SKILL.md 2단계는 "브랜치 모드의 `git diff`는 커밋하지 않은 작업 트리 변경까지 포함합니다"라고 적지만, 실제 명령 `git diff "$(git merge-base "$base" HEAD)"`는 추적 중인 파일의 변경만 보여 주고 미추적 새 파일은 뺀다. 커밋 전 브랜치에서 브랜치 모드로 퀴즈를 만들면 새 스크립트·템플릿·문서가 설명 절과 문항의 입력에서 빠지고, 읽는 사람은 그 사실을 알 수 없다.
