# K-0050: issue-audit 러너가 `LC_ALL=C`에서 첫 검사에서 멈춘다

- **유형**: known issue
- **등재일**: 2026-11-28
- **출처**: 이슈 #147 (spec 제외 `보류` 항목, 이슈 완료 시 등재 질의 승인)
- **위험도**: 낮음(LOW)
- **수용 사유**: #145 이전에도 있던 동작이고, 기본 로케일(`C.UTF-8`·`en_US.UTF-8`)에서 실행하면 러너가 끝까지 돌아 실패 0건으로 끝난다. 이 repo의 러너 실행은 `LC_ALL`을 비운 셸이 기준이라 평소 회귀에는 영향이 없다. 원인을 확인하지 않았고 이슈 #147의 범위(헬퍼와 세 러너의 로케일 고정) 밖이라 이번 이슈에서 고치지 않는다.
- **재검토 조건**: issue-audit 러너를 `LC_ALL=C` 셸에서 돌려야 하는 상황이 생길 때, 이 현상 때문에 회귀 결과를 잘못 읽은 사례 관측 시, 또는 issue-audit 러너에 로케일 고정을 더할 때
- **상태**: 수용

## 내용

`LC_ALL=C bash issue-audit/tests/run-tests.sh`는 `매트릭스 추출: 표 행 5개 기대, 실제 0개` 1건이 실패하고 `passed: 1, failed: 1`로 끝나, 나머지 검사를 실행하지 않는다. 기본 로케일에서는 같은 러너가 429건 통과·실패 0건이다. `LC_ALL=C`를 물려받은 셸에서 repo 전체 회귀를 돌리면 이 러너만 실패로 보인다.
