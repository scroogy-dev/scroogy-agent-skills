# K-0036: git-review doc 카테고리에 확인 관점 목록과 실패 시나리오가 없다

- **유형**: 기술부채
- **등재일**: 2026-11-22
- **출처**: 이슈 #142 (spec 제외 보류 항목)
- **위험도**: 중간(MEDIUM)
- **수용 사유**: 확인 관점 목록과 실패 시나리오를 코드 카테고리(버그·보안·성능)에 먼저 두고, 그 결과를 본 뒤 doc 카테고리에 맞는 형태를 정하기로 했다. 대상 수집, 변경 줄 읽기, 인용 위치 재확인, 변경 전부터 있던 결함의 처리는 원본 문서 선언 repo에도 지금 적용된다.
- **재검토 조건**: 원본 문서 선언 repo에서 git-review를 여러 번 실행해 doc 카테고리 리뷰 포인트의 형식을 정할 수 있을 때, 코드 카테고리 확인 관점 목록을 바꿀 때, 또는 git-review doc 카테고리 표를 바꿀 때
- **상태**: 수용

## 내용

git-review 테크 리뷰 3단계의 확인 관점 목록과 발견 처리의 실패 시나리오는 코드 카테고리에만 적용되고 doc 카테고리 세트에는 적용되지 않는다. 원본 문서 선언 repo의 리뷰는 doc 카테고리를 판정할 관점 목록 없이 수행된다.

## 재검토 이력

없음
