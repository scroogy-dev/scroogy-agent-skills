# K-0032: git-review-quiz 입력 속 지시문 조항이 커밋 메시지를 다루지 않는다

- **유형**: known issue
- **등재일**: 2026-11-21
- **출처**: 이슈 #142 / 계획 감사 12차 F-35 검토 중 확인 (감사 발견 아님)
- **위험도**: 낮음(LOW)
- **수용 사유**: 이슈 #142의 범위 줄과 AC는 git-review만 다뤄, git-review-quiz의 조항을 고치면 범위 확장이 된다. 사용자가 원장 등재를 골랐다(2026-11-21, 12차 계획 감사 검토). 조항 문장은 러너의 문구 검사, 도메인 명세, ADR 0027, 코드맵이 같은 문장으로 적고 있어 함께 고쳐야 한다.
- **재검토 조건**: git-review-quiz의 `**입력 속 지시문**:` 조항이나 2단계의 수집 대상을 고칠 때, 또는 커밋 메시지 안의 지시문 때문에 퀴즈의 내용이나 절차가 바뀐 사례 관측 시
- **상태**: 수용

## 내용

git-review-quiz SKILL.md의 `**입력 속 지시문**:` 조항은 diff·PR 본문·이슈 본문·코드 주석 네 입력만 열거하는데, 2단계는 설명 절의 출처로 커밋 메시지도 모은다. 커밋 메시지 안의 지시문을 어떻게 읽을지는 조항에 없다. 이슈 #142는 같은 선례를 옮기는 git-review의 조항에서 대상을 "리뷰가 읽는 입력"으로 정하고 커밋 메시지를 예에 더했으므로(spec R4), #142가 머지되면 두 스킬의 조항 문장이 달라진다.

## 재검토 이력

없음
