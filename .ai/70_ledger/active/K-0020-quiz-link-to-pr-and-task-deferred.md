# K-0020: PR 안내와 Task 진행에 이해 점검 퀴즈 연결이 없다

- **유형**: 기술부채
- **등재일**: 2026-11-01
- **출처**: 이슈 #130 (spec 제외 보류 항목)
- **위험도**: 중간(MEDIUM)
- **수용 사유**: 퀴즈를 누가 언제 풀지(PR 리뷰 전 리뷰어, Task 완료 때 작성자 등) 운영 방식이 정해지지 않았다. 방식 없이 PR 안내나 Task에 연결하면 쓰지 않는 단계가 절차에 남는다. `git-review-quiz`는 단독으로 호출할 수 있어 필요할 때 지금도 쓸 수 있다.
- **재검토 조건**: 퀴즈 운영 방식(풀 사람·시점)을 정할 때, 또는 PR 리뷰 전후로 `/git-review-quiz`를 따로 호출하는 사용이 반복될 때
- **상태**: 수용

## 내용

git-pr PR 본문과 issue-work Task 진행 어디에도 이해 점검 퀴즈(`git-review-quiz`)로 가는 안내가 없다. 변경 이해를 점검하려면 리뷰어나 작성자가 `/git-review-quiz`를 따로 호출해야 한다.

## 재검토 이력

없음

- **발생확률**: 통상 사용. PR마다 안내가 없으므로 정상 사용 경로에서 매번 나타난다.
