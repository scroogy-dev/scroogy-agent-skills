# K-0026: ai-workspace 구간 판정이 여러 백틱 코드 스팬 안의 `<!--`를 HTML 주석으로 읽는다

- **유형**: known issue
- **등재일**: 2026-11-06
- **출처**: PR #135 코멘트 스레드
- **위험도**: 중간(MEDIUM)
- **수용 사유**: 발생확률이 낮다. 삭제가 생기려면 여러 백틱 코드 스팬 안의 `<!--`가 표준 구간에 있고 그 뒤에 사용자 섹션과 닫는 `-->`가 차례로 있어야 하며, 저장소의 안내도·인덱스와 템플릿에 이 형태가 없다(2026-11-06 검색). 영향은 사용자 섹션 삭제지만 git으로 추적하는 repo에서는 복구할 수 있다. 고치려면 백틱 길이를 맞추는 스캔을 awk 사본 두 곳에 더해야 하고, 같은 종류의 패치를 반복하다 새 결함이 생긴 선례가 있다(K-0010).
- **재검토 조건**: 실제 안내도·인덱스에서 이 경계로 사용자 내용이 사라지거나 표준 구간이 중복된 사례 관측 시, 또는 `sync-owned.sh`·`check-context.sh`의 `MD_TRACK_AWK` 주석 판정 변경 시
- **상태**: 수용

## 내용

`sync-owned.sh`와 `check-context.sh`의 `scan_comment`는 백틱 하나로 감싼 코드 스팬만 지운 뒤 `<!--`를 찾으므로, 여러 백틱 코드 스팬 안의 `<!--`를 주석 시작으로 읽고 다음 `-->`까지의 제목과 표를 세지 않는다. 표준 구간 안이면 그 뒤 사용자 섹션이 종료 코드 0으로 사라지고, 사용자 구간 안이면 표준 구간이 파일 끝에 중복 추가되지만 사용자 내용은 남는다. `profile` 표 바로 앞이면 판정은 사용자에게 묻고 `--profile` 쓰기는 파일을 바꾸지 않고 실패한다.
