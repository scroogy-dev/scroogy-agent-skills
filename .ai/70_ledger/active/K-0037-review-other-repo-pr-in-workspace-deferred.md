# K-0037: git-review가 다른 저장소의 PR을 워크스페이스 안의 해당 저장소 디렉토리에서 리뷰하지 않는다

- **유형**: 기술부채
- **등재일**: 2026-11-22
- **출처**: 이슈 #142 (spec 제외 보류 항목)
- **위험도**: 낮음(LOW)
- **수용 사유**: git-review는 PR 링크의 저장소가 현재 저장소와 다르면 리뷰를 시작하지 않고 알리므로 다른 저장소를 잘못 리뷰하지 않는다. 사용자가 해당 저장소 디렉토리에서 다시 실행하면 리뷰할 수 있다. 워크스페이스 루트에서 실행하는 일이 잦아지면 판단하기로 했다.
- **재검토 조건**: 멀티 repo 워크스페이스에서 다른 저장소의 PR로 git-review를 실행해 중단된 사례가 반복될 때, 또는 git-review 대상 수집 1단계의 저장소 확정 규칙이나 `resolve-target.sh`의 대조 방식을 바꿀 때
- **상태**: 수용

## 내용

멀티 repo 워크스페이스에서 git-review를 실행한 디렉토리의 저장소와 다른 저장소의 PR 링크를 주면, git-review는 두 저장소가 다르다는 사실을 알리고 끝난다. 워크스페이스 안에서 그 저장소의 디렉토리를 찾아 리뷰하는 절차는 없다.

## 재검토 이력

없음
