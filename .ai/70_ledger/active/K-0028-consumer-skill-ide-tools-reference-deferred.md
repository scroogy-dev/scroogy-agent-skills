# K-0028: 소비 스킬 본문이 IDE 도구 우선 규칙(`ide-tools.md`)을 직접 참조하지 않는다

- **유형**: 기술부채
- **등재일**: 2026-11-07
- **출처**: 이슈 #136 (spec 제외 보류 항목)
- **위험도**: 낮음(LOW)
- **수용 사유**: 안내도 규칙 표가 스킬 실행에도 선행 적용되어, IntelliJ MCP가 연결된 dev repo에서는 스킬을 실행할 때도 `ide-tools.md`를 읽는다. 규칙 표만으로 IDE 도구 사용이 늘어나는지 효과를 본 뒤에 스킬 본문 참조가 필요한지 판단한다.
- **재검토 조건**: 규칙 표가 있는데도 `code-map`·`git-review` 등 코드를 탐색하는 스킬 실행에서 IDE 도구 없이 grep만 쓴 사례가 반복될 때, 또는 `context-loading.md`의 `ide-tools.md` 라우팅이나 규칙 표의 스킬 선행 적용 문장이 바뀔 때
- **상태**: 수용

## 내용

`code-map`·`git-review` 등 코드를 탐색하는 스킬의 본문은 `ide-tools.md`를 직접 가리키지 않는다. 스킬 실행 중의 도구 선택은 안내도 규칙 표와 `context-loading.md` 라우팅에만 기댄다. 규칙 표를 읽지 않은 세션에서 스킬을 실행하면 IDE 도구 대신 grep으로 탐색할 수 있다.

## 재검토 이력

없음

<details>
<summary>근거·배경 펼치기</summary>

- **영향**: 기능 저하. 스킬은 그대로 동작하고, 심볼·호출 관계 탐색의 정확도와 효율만 떨어진다.
- **발생확률**: 특수 조건·엣지. 규칙 표가 스킬 실행에도 선행 적용되므로 규칙 표를 읽지 않은 세션에서만 나타난다. 2026-11-07 기준으로 grep 사용을 본문에 명시한 소비 스킬은 없다.
- **채택하지 않은 대안**: 이슈 #136에서 소비 스킬 본문에 `ide-tools.md` 참조를 더하는 안. 규칙 표의 효과를 보기 전이라 보류했다([ADR 0029](../../50_adr/active/0029-ide-tools-rule-dev-profile-distribution.md) 대안 절).
- 같은 이슈의 다른 보류 항목(호출 기록 훅·grep 안내 훅, 다른 IDE의 MCP)은 등재하지 않았다.

</details>
