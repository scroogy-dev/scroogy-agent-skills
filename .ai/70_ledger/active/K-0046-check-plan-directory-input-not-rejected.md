# K-0046: issue-audit 추적성 헬퍼가 파일 자리의 디렉토리를 입력 오류로 거르지 않는다

- **유형**: known issue
- **등재일**: 2026-11-27
- **출처**: 이슈 #145 (audit 발견 F-20 처리, `--response` 승인)
- **위험도**: 낮음(LOW)
- **수용 사유**: issue-audit 절차가 `check-plan.sh`에 넘기는 인자는 늘 이슈 본문·spec·plan 정규 파일이라 표준 호출에서는 생기지 않는다. 잘못 넘겨도 판정이 조용히 통과하지 않고 종료 코드 1과 위반·대조 불가 행이 나와 감사인이 알아챈다. 이슈 #145 이전(main `3f0e804`)부터 있던 결함이고 이번 이슈가 바꾼 입력 검사 구간도 아니어서, 최종 감사 7차 뒤에 스크립트를 고쳐 전체 재감사를 받을 만한 실익이 없다.
- **재검토 조건**: 디렉토리나 정규 파일이 아닌 경로를 넘겨 AC 대조·추적성 결과를 잘못 읽은 사례 관측 시, 또는 `check-plan.sh`의 인자·입력 검사 구간을 바꿀 때
- **상태**: 수용

## 내용

`check-plan.sh`의 입력 검사는 각 문서 인자에 `[ -r "$f" ]`만 적용해, 읽을 수 있는 디렉토리가 파일처럼 통과한다. `--ac`의 이슈 본문 자리에 디렉토리를 주면 `대조 불가: 이슈 본문에 AC 없음`과 종료 코드 1이 나와 실제로 AC가 없는 본문과 구분되지 않고, `--trace`에 주면 Task 누락·AC 테스트 계획 누락 행이 나온다. 없는 경로는 지금도 입력 오류(종료 코드 2)로 끝난다.

## 재검토 이력

없음
