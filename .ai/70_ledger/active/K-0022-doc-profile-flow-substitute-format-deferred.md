# K-0022: doc 프로파일 저장소 PR에 호출 흐름·시퀀스를 대신할 형식이 없다

- **유형**: 기술부채
- **등재일**: 2026-11-01
- **출처**: 이슈 #130 (spec 제외 보류 항목)
- **위험도**: 중간(MEDIUM)
- **수용 사유**: doc 저장소의 PR 경험이 적어, 문서 구조 변경 전후 표 같은 형식이 리뷰에 실제로 도움이 되는지 판단할 근거가 없다. 경험 전에 형식을 정하면 실제 리뷰 흐름과 어긋난 규칙을 유지하게 된다.
- **재검토 조건**: doc 프로파일 저장소에서 git-pr로 PR을 여러 번 만들어 테크 관점에 쓸 형식을 정할 수 있을 때, 또는 doc 저장소 PR의 테크 관점이 문서 구조 변경을 보여 주지 못해 리뷰에 지장이 생긴 사례 관측 시
- **상태**: 수용

## 내용

git-pr 테크 관점의 `호출 흐름`은 트리와 시퀀스 다이어그램 형식만 정한다. SSoT가 `원본 문서`인 doc 저장소에는 문서 구조 변경(문서 추가·이동, 섹션 재배치)을 보일 전용 형식이 없어, 작성자가 매번 형식을 새로 정한다. [ADR 0026](../../50_adr/active/0026-acceptance-criteria-across-issue-spec-pr.md)이 이 항목을 보류로 남겼다.

## 재검토 이력

없음
