### 경계 검증

- PR 수집은 기존 `gh pr diff --repo`를 사용한다. 퀴즈 산출 이름 규칙과 커밋 메시지 관련 입력 속 지시문 조항은 기존 범위를 따른다.
- 퀴즈의 헬퍼 호출은 수집에 한정된다. K-0031도 주변 파일 읽기와 발견 성립 확인은 git-review에만 적용된다고 명시한다.
- K-0051~K-0053은 감사와 응답에서 결정한 원장 기록이다. 새 퀴즈 옵션·산출 형식은 0건이다.

### 도메인/계약 정합성

- ADR 0001·0002에 따라 퀴즈 자체의 `scripts/`에 실행 가능한 사본을 두고 `tests/`에서 대조한다. ADR 0021의 사본 안내와 `cmp` 선례를 따른다.
- GitHub 연동 계약의 PR 수집 경로와 ADR 0027의 브랜치 모드 산출 경로에 충돌이 없다. K-0025의 원장 해소 시점에는 ADR 0018을 적용했다.
- 호출 흐름의 트리와 시퀀스가 예전 `git diff`를 가리킨다. 코드베이스 색인 갱신이 필요해 보입니다 (`/code-map`). Task N이 이 갱신을 명시한다. [호출 흐름](../../../60_codebase/git-review-quiz/quiz-call-flow.md#L22) · [색인](../../../60_codebase/index.md#L28)
