### 경계 검증

- PR 모드는 같은 `gh pr diff --repo` 경로를 사용한다. 산출 파일 이름과 설명 절의 입력 종류는 기존 범위와 일치한다. `--marked` 구현은 헬퍼 사본에 포함되고 퀴즈 호출은 `--base`만 사용한다.
- 원장 두 항목의 등재는 이슈 #150의 1차 감사 후속 기록이다. 새 실행 옵션과 산출 형식 추가는 0건이다.

### 도메인/계약 정합성

- ADR 0001·0002의 단독 배포와 같은 위치의 러너 구성을 확인했다. GitHub 계약의 PR 경로 `--repo`와 ADR 0027의 퀴즈 산출 경로가 유지된다. K-0025의 PR 번호 확정 시점은 ADR 0018을 적용했다.
- 퀴즈 도메인 명세 입력 줄의 대소문자 경계는 Task 4에 남아 있다. [퀴즈 명세](../../../40_domain/specs/git-review-quiz.md#L11)
- 퀴즈 호출 흐름의 2단계 트리와 시퀀스가 이전 `git diff`를 가리킨다. 코드베이스 색인 갱신이 필요해 보입니다 (`/code-map`). [호출 흐름](../../../60_codebase/git-review-quiz/quiz-call-flow.md#L22) · [색인](../../../60_codebase/index.md#L28)
