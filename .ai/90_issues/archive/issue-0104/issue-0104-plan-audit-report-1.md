- spec bash 블록 17개와 plan의 고유 bash 블록 4개를 repo 루트에서 `/bin/bash`로 실행했다. Task가 참조하는 spec 명령은 중복 실행하지 않고 같은 실행 결과로 대조했다.
- 통과·위반은 각 블록의 선언된 출력 계약으로 판정했다. `grep`의 무매칭 종료 코드 1은 `출력 0건이면 통과` 조건에서는 통과이며, awk의 `0` 출력도 통과다.
- spec 공통 명령이 호출한 전체 스킬 테스트는 위반 출력 없이 종료했다. 검증 실행은 제품 구현 완료를 뜻하지 않는다.
