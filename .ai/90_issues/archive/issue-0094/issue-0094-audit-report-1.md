### 경계 검증

- **스펙 요구사항의 제외 목록 침범 여부**: 없음. 기존 active/archive 이슈 문서는 소급 수정하지 않았다. 상주 워크플로우 사본은 R5가 명시한 갱신 대상이다. issue-audit는 절차 구조를 유지하고 명칭·대조 원천만 고쳤으며 summary 템플릿과 전제 하위 분류도 바꾸지 않았다.
- **스펙에 없는 추가 구현 여부**: 없음. 변경은 요구사항이 지정한 템플릿·스킬 본문·상주 사본 7개 파일과 이슈 작업 문서 3개에 한정된다.

### 도메인/계약 정합성

- 계약 인덱스에는 관련 문서가 없고, 도메인 인덱스에도 이 변경을 제한하는 정책·명세가 없다.
- ADR 0001은 새 결정적 헬퍼가 생길 때의 배치 규칙이다. 이번 변경에는 새 헬퍼가 없고 기존 `scripts/`·`tests/` 배치를 바꾸지 않아 충돌하지 않는다.
- 코드베이스 색인은 비어 있어 실제 변경 파일과 diff를 직접 확인했다. 상주 워크플로우 사본은 템플릿과 바이트 단위로 일치한다.
- GitHub Issue #94 본문과 로컬 스펙의 목표·결정·작업 범위가 일치한다. 스펙 단계에서 확정한 세부 형식은 `## 전제`에 남아 있다.
