<details>
<summary>근거·재현·등급 변경 펼치기</summary>

- `<html>` 시작 태그만 읽도록 고친 덕분에 CSS·JS 속 문자열을 완료 속성으로 오인하던 부분은 해소됐다. 렌더러 실패도 이제 위반으로 분리한다.
- 남은 검사는 완료 속성 부재와 `pre#quiz-source` 텍스트의 일치만 본다. 원문이 실제로 보이는지 확인하지 않는다.
- 동일한 원문 `# Example\n`으로 보이는 `<pre>`, `hidden` 속성이 있는 `<pre>`, `style="display:none"`인 `<pre>` 세 DOM을 만들었다. spec R7 첫 폴백 블록에서 추출한 Python 판정은 모두 종료 코드 0이고, 실제 `rendered()` 함수는 모두 종료 코드 1이다. 따라서 세 경우 모두 현재 폴백 검증을 통과한다.
- Playwright로 `hidden` DOM을 직접 열었을 때 `rendered=false`, `hidden=true`, `display="none"`, `getClientRects().length=0`이었다. 빈 화면인데 현재 판정은 통과하는 반례다. 원문을 다른 글자로 바꾼 DOM은 Python 판정 종료 코드 1로 올바르게 거부했다.
- Task 2의 템플릿 기본 표시·숨김 속성 검사는 유효하다. 다만 정상 템플릿에서 실행 중 JS가 원문을 숨긴 뒤 라이브러리 실패로 반환하는 결함, CSS가 원문을 감추는 결함은 DOM 텍스트만 검사해서 잡을 수 없다.
- 이전 완료 기준의 “원문이 숨겨지거나 바뀐 입력은 실패” 중 숨김 판정만 잔여다. 라이브러리를 못 불러오는 예외 상황에서 발생하는 검증 공백이므로 두 축을 다시 판정해 HIGH에서 MEDIUM으로 좁혔다. 신규 발견 번호는 부여하지 않았다.
