- 아래 명령은 비관리자 환경에서 재현하며 실제 저장소 파일을 변경하지 않는다.

```bash
H="$PWD/issue-work/scripts/check-ledger-links.sh"
T=$(mktemp -d)
mkdir "$T/.ai"
printf '[K](%s)\n' '70_ledger/active/K-0001-a.md' > "$T/.ai/a-unreadable.md"
printf '# readable\n' > "$T/.ai/z-readable.md"
chmod 000 "$T/.ai/a-unreadable.md"
"$H" "$T/.ai"
rc=$?
chmod 600 "$T/.ai/a-unreadable.md"
printf 'rc=%s\n' "$rc"
# 실제: awk 읽기 오류와 rc=0. 기대: 검사 불가 진단과 rc=2.
```
