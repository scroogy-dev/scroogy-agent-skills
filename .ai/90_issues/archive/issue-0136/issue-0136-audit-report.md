- **제외 목록 침범**: 없음. 전역 파일·훅·미리 적재·local 쌍·doc 전용 배포·소비 스킬 직접 참조·다른 IDE의 변경이 없다.

- **변경 범위**: `origin/main...HEAD`에 커밋 차이가 없고 구현은 작업 트리에 있다. `git diff`의 14개 추적 파일과 새 규칙·ADR·fixture·이슈 문서를 함께 읽었다.
- **사용자 내용 보존**: fixture의 인라인 규칙·사용자 행·다음 기술 스택 섹션이 그대로 남는다. 선언 보정 모의 실행에서도 추가한 사용자 행이 유지되며 기존 testing-principles 행을 중복 삽입하지 않는다.

### 도메인/계약/ADR 정합성

- `.ai/AI-CONTEXT.md`의 SSoT 선언은 소스 코드다. 명세·색인만으로 판정하지 않고 `SKILL.md`·템플릿·헬퍼·러너를 직접 대조했다.
- ADR 0001의 헬퍼·테스트 배치와 배포 제외, ADR 0008·0023의 버전 고정 파일 배포와 조건부 라우팅, ADR 0028의 사용자 작성 규칙 표 보존과 일치한다.
- ADR 0029는 기존 결정을 유지하며 dev 단일 규칙 파일과 dev 행 보강 경로를 더한다. `profile`과 SSoT 선언을 별개로 다루는 기존 계약도 유지한다.
- 명세 `specs/ai-workspace.md`는 새 배포 파일과 12종 검사를 반영했다. Agent Skills 설치 경로·포맷 계약은 바뀌지 않았다.
- **색인 유지보수 의견**: 코드베이스 색인 갱신이 필요해 보입니다 (`/code-map`). `60_codebase/ai-workspace/init-call-flow.md`의 dev 배포 목록에는 `ide-tools.md`가 없고, `update-call-flow.md`는 최신본 목록과 검사 수를 여전히 11종으로 적는다. 요구사항에 코드맵 갱신 의무는 없어 1단계 판정에는 반영하지 않았다.
