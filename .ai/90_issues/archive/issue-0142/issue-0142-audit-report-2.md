<summary>근거·상세 설명 펼치기</summary>

<summary>근거·상세 설명 펼치기</summary>

src/file 한 개를 수정한 임시 저장소에서 상대 경로 환경을 설정했다. 같은 셸의 git merge-base main HEAD와 git diff --name-only main은 성공했고 후자는 src/file을 냈다. 헬퍼는 루트로 cd한 뒤 main을 해석하지 못해 종료 코드 1과 빈 표준 출력을 냈다. 같은 디렉토리에서 두 환경 변수를 절대 경로로 바꾸면 성공했다. 별도로 assume-unchanged 표시를 한 파일에서도 --marked가 상대 경로에서는 종료 코드 1, 절대 경로에서는 종료 코드 0과 h src/file 한 행을 반환했다. 계획 Task 1은 하위 디렉토리 호출을 지원하며, 스펙의 1차 보정 전제는 이 두 변수가 Git의 결과를 따른다고 명시한다.
