### 상세 분석

#### F-8: PR ref를 받아도 고정한 head 객체가 없을 수 있다

- **위험도**: 🟡 중간(MEDIUM)
- **영향 축**: 스펙·기능 달성 차단
- **발생확률 축**: 특수 조건·엣지
- **카테고리**: 버그
- **관점**: 모호성 · AC4
- **계보**: F-2 잔여
- **권장 조치**: PR ref를 받은 뒤 고정 SHA의 커밋 존재 여부를 확인한다. 없으면 그 SHA로 원격 파일을 조회한다.
- **완료 기준**:
  - fetch는 성공하고 최초 SHA가 로컬에 없는 경우 고정 SHA로 원격 파일을 조회한다.
  - 모든 조회 수단에서 고정 SHA의 파일을 읽지 못한 경우 읽지 않은 파일과 사유를 기록한다.

<details>
<summary>근거·상세 설명 펼치기</summary>
