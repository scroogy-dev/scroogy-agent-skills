도구 목록 헬퍼는 설치 제외 경로인 `ai-workspace/tests/`에 있다(설치 경로 계약, ADR 0001). dev 규칙 덮어쓰기와 local 파일 보존은 ADR 0028의 소유 구분을 따른다. ADR 0023의 로컬 서버 절과 테스트 라우팅에 관한 Task 5 추가 검증은 무출력이었다. ADR 0029와 0030의 남은 충돌은 F-3에 기록했다.

### 검증 실행 기록

- GitHub 이슈 본문은 로컬 본문 사본과 일치했다(말미 개행 제외). 스펙 기준 커밋은 main 분기점과 같았다. Task 0~5의 수행 모델은 모두 Anthropic, 이번 최종 감사는 OpenAI다.
- 현재 연결된 IntelliJ MCP의 도구 이름 101개를 정렬해 fixture와 대조했다. 스펙의 [D] 47개와 [QD] 4개의 결과는 위 표에 각각 기록했다. local 파일의 테스트 층·셸 칸이 비어 있어 스펙이 지정한 Bash를 사용했다. 마지막 항목은 저장소의 스킬 러너 13개를 모두 호출한다.
- Task 3은 내부 일치 검사와 목록 헬퍼, Task 4는 context-loading의 두 참조 위치를 바꾸며 각각 전용 검사 기준을 갖는다. 여덟 일치 검사 변형과 네 라우팅 변형이 통과했다. Task 3에 남은 검증 공백은 F-1·F-7에 기록했다. Task 1은 결정 기록, Task 2는 배포 규칙 문구·구조, Task 5는 문서 동기화이며 Task 2의 R1~R12 전용 검증 명령도 실행했다.
- F-1·F-2·F-7은 임시 사본을 사용했다. 서버 후보는 이름 목록의 개수만 확인했다. 디버거 삭제 범위는 도구 정의를 확인했으며 서버·디버거를 기동하거나 중단점을 수정하지 않았다.
