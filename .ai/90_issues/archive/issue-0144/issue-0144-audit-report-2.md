#### F-9: 기존 agent 중단점을 갱신한 경우에도 정리 목록에 넣을 수 있다

- **위험도**: 🟡 중간(MEDIUM)

- **완료 기준**
  - 기존 agent 예외·메서드 중단점과 대상이 겹쳐도 그 설정과 ID가 보존되고 제거 요청에 들어가지 않는다.
  - 예외·메서드 설정이 `created=true`이면 응답의 ID만 삭제 후보가 된다. `created=false`인 응답만 있을 때는 삭제 요청이 0건이다.

<summary>근거 펼치기</summary>
