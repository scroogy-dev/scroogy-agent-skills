### Task 1: description 트리거 정비 (권고 1, 4 + 하 심각도 2건)

- [ ] 완료
- **목표**: description만으로 올바른 스킬이 트리거되도록 4개 스킬의 frontmatter를 정비한다.
- **작업 내용**:
  1. `ai-workspace`: 트리거 키워드 추가 (`.ai 디렉토리`, `AI-CONTEXT.md`, `안내도`, `workspace 초기화` 등) + ai-workspace-directory와의 역할 구분(층/로비) 명시
  2. `git-review-context`: "git-review 실행 전 사전 분석 단계이며 사용자가 명시적으로 요청한 경우에만 실행" 제약을 description으로 승격
  3. `readme-sync`: 다른 스킬과 동일한 "X, Y 시 사용합니다" 트리거 패턴 적용
  4. `issue-work`: description의 괄호 플래그 표기(`--workflow-only`, `--resume`) 제거, 자연어 키워드(이어하기, resume 등)는 유지
- **완료 기준**: 4개 스킬의 description이 갱신되고, ai-workspace ↔ ai-workspace-directory, git-review ↔ git-review-context 간 트리거 회색지대가 description 차원에서 해소됨
