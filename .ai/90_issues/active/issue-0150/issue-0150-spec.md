# Issue #150 스펙 git-review-quiz: 브랜치 모드가 git-review 수집 헬퍼 사본으로 미추적 새 파일까지 모으고 안내를 실제 수집 대상과 맞춘다

## 목표 (Goal)

git-review-quiz 브랜치 모드가 커밋 전 미추적 새 파일까지 퀴즈 입력에 넣고, SKILL.md 안내가 실제 수집 대상과 같아진다.

---

## 요구사항 (Requirements)

### 포함

- R1: git-review-quiz 브랜치 모드가 git-review와 같은 수집 헬퍼 사본으로 커밋한 변경, 미커밋 변경, 미추적 새 파일을 모은다. (함께 해소: K-0025)
- R2: 헬퍼 수집이 실패하면 빈 변경으로 퀴즈를 만들지 않고 실패 사유를 알린다.
- R3: git-review-quiz SKILL.md 2단계 안내가 브랜치 모드에서 들어가는 변경과 빠지는 경로를 헬퍼 동작과 같게 적는다.
- R4: 원장 K-0031의 수용 범위에 git-review-quiz 브랜치 모드를 더한다.

### 제외

- K-0024(브랜치 이름 치환 뒤 산출 파일 이름 충돌): 보류(원인이 다르고 파일 이름 가독성 결정이 따로 필요하다)
- K-0032(입력 속 지시문 조항이 커밋 메시지를 다루지 않음): 보류(원인이 다르고 재검토 사례가 없다)
- git-review 3단계 읽기 기준(`--marked`로 표시한 경로 목록)을 퀴즈에 옮기기: 보류(퀴즈에는 주변 파일을 읽는 기준을 정한 절이 없어 이번에는 수집만 맞춘다)
- PR 모드 수집 변경: 불필요(`gh pr diff`가 PR 변경 전부를 받는다)

## 완료의 정의 (Definition of Done)

- [ ] AC1: 브랜치 모드에서 커밋하지 않은 미추적 새 파일이 변경 파일 목록과 퀴즈 입력 patch에 들어간다. (R1)
- [ ] AC2: 브랜치 모드에서 `.ai/99_workspace/` 아래 미추적 파일과 무시 규칙에 걸린 미추적 파일은 변경 파일 목록에 들지 않는다. (R1)
- [ ] AC3: git-review-quiz의 수집 헬퍼가 git-review 원본과 바이트 단위로 같다. (R1)
- [ ] AC4: 헬퍼 종료 코드가 0이 아니면 퀴즈 파일을 만들지 않고 실패한 명령과 사유를 알린다. (R2)
- [ ] AC5: SKILL.md 2단계 안내가 브랜치 모드에서 들어가는 변경과 빠지는 경로를 헬퍼 동작과 같게 적는다. (R3)
- [ ] AC6: 원장 K-0031의 내용과 재검토 조건이 git-review-quiz 브랜치 모드를 포함하고, 재검토 이력에 이 이슈가 남는다. (R4)

## 결정 사항 (Decisions)

- D1 브랜치 모드 대상: git-review 브랜치 모드와 같다. 지금 작업 트리를 전부 스테이징해 커밋하면 들어갈 변경이며, 커밋한 변경, 미커밋 변경, 미추적 새 파일이 들어간다. 무시 규칙에 걸린 미추적 파일과 `.ai/99_workspace/` 아래 미추적 파일은 빠진다. 작업공간 제외는 디렉토리 이름의 대소문자를 구분한다. 대소문자를 구분하지 않는 볼륨에서 디스크의 디렉토리 이름이 `.ai/99_workspace`와 대소문자만 다르면 그 아래 미추적 파일은 Git이 보고하는 실제 표기로 들어간다(K-0051). 그 밖에 Git이 스테이징 내용을 정하는 경로는 Git의 결과를 따른다(K-0031).
- D2 헬퍼 사본: `git-review-quiz/scripts/collect-branch-changes.sh`에 두고 `git-review/scripts/collect-branch-changes.sh`와 바이트 단위로 같게 유지한다. 한쪽을 고치면 다른 쪽도 고친다(ADR 0002·0021 선례).
- D3 쓰는 모드: 퀴즈는 헬퍼의 `--base`만 쓴다. `--marked`는 바이트 동일을 지키려고 사본에 남는다.
- D4 merge-base 해시: 2단계에서 한 번 구해 보관하고, 헬퍼 `--base`와 설명 절 출처의 커밋 메시지 수집에 같이 쓴다.
- D5 원장: K-0031은 새 번호를 따지 않고 기존 항목의 범위를 넓힌다. K-0025는 이 이슈의 PR로 해소한다.
- D6 머리 주석: 원본 헬퍼의 머리 주석을 두 스킬에 맞는 문구로 고친 뒤 복제한다. git-review 헬퍼는 주석만 바뀐다(2026-11-28 대화에서 결정).
- D7 수집 실패: merge-base를 구하지 못했거나 헬퍼 종료 코드가 0이 아니면 실패다. 종료 코드 0에 출력이 없으면 변경 파일 0개이고 실패로 보지 않는다. 변경 파일 0개일 때의 퀴즈 처리는 이번에 바꾸지 않는다.
- D8 K-0032: 이번 작업은 2단계의 diff 수집을 헬퍼로 바꿔 K-0032 재검토 조건의 "2단계의 수집 대상을 고칠 때"에 맞지만, 커밋 메시지 수집과 `**입력 속 지시문**:` 조항은 바꾸지 않아 계속 수용한다. K-0032 `재검토 이력`에 이 판단을 적고 재검토 조건을 설명 절 출처 입력의 변경으로 좁힌다(계획 감사 1차 F-1, 2026-11-28).
