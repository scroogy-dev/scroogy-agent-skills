  - Playwright MCP 확인(로컬 HTTP 서버로 제공, `file:` 프로토콜은 MCP가 막음):
    - 목차: h2·h3 12개 항목, 1200px에서 본문 왼쪽, 390px에서 본문 위.
    - 객관식: 오답 (a) 클릭 시 "오답입니다. 정답은 (b)입니다."와 정답 보기 강조, 정답·해설 접기 열림. 정답 (b) 클릭 시 "정답입니다."
    - 주관식: 입력란과 `모범 답안 보기` 버튼이 있고, 버튼을 누르면 정답·해설 접기가 열린다.
    - 접기: 처음에는 모두 닫힘, 요약을 누르면 열림.
