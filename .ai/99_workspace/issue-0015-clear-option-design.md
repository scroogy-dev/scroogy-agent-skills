# issue-0015: `--clear` 옵션 설계

> Task 2 산출물. Task 3에서 이 초안을 `issue-work/SKILL.md`에 반영한다.

## 설계 결정

| 결정 사항 | 내용 | 근거 |
|-----------|------|------|
| 기존 `## 이슈 완료 시`와의 관계 | `--clear`는 완료 절차의 상위 집합. 완료 절차(확인→summary 갱신→이관)를 포함하고 99_workspace 정리·이슈 댓글 질의를 추가 수행 | 절차 중복·모순 제거. 완료 섹션에는 `--clear` 안내 한 줄만 추가 |
| 미완료 Task가 있을 때 | 미완료 목록을 보여주고 계속할지 질의 후 진행 | archive는 "완료 또는 종료된 이슈" 보관소 — 중단·종료 케이스도 지원해야 함 |
| 동작 순서 | 완료 확인 → summary 갱신 → 댓글 질의 → archive 이관 → 99_workspace 정리 | 댓글 요약은 summary 기반이므로 갱신 직후·이관 전에 질의가 자연스러움 |
| 99_workspace 정리 기준 | 파일 목록 제시(`.gitkeep` 제외·보존) → 보존 가치 있는 파일은 `archive/issue-<번호>/`로 이동 제안 → 나머지 삭제 확인 후 삭제 | 삭제는 파괴적 동작이므로 목록 확인·승인 필수. 디렉토리 유지용 `.gitkeep`은 항상 보존 |
| 댓글 거절·연동 불가 시 | 댓글 단계만 건너뛰고 나머지 정리 계속, 사용자에게 보고 | 댓글은 부가 기능 — 정리 본연의 동작을 막지 않음 |
| active에 이슈가 여러 개일 때 | 각 이슈 디렉토리에 대해 완료 확인~이관을 반복 후 99_workspace 정리 1회 | 새 이슈 시작 시 기존 이슈를 이관하므로 드물지만 방어적으로 정의 |
| 이슈 번호 ↔ GitHub 이슈 매핑 | 디렉토리명 `issue-<번호>`에서 앞자리 0을 제거한 번호를 GitHub 이슈 번호로 사용 | 기존 관례 (issue-0015 ↔ #15) |

## SKILL.md 반영 초안

### 1. 프론트매터 `description` 키워드 추가

기존 끝부분에 `이슈 정리, 작업공간 정리, 정리(--clear)` 트리거 키워드를 추가한다.

### 2. `## 옵션` 섹션에 추가

```markdown
### `--clear`

진행 중인 이슈를 마무리하고 작업공간을 비워 다음 이슈를 준비한다.

- **용도**: 이슈 작업이 끝났을 때(완료 또는 중단·종료) 이슈 디렉토리 이관, 임시 파일 정리, 이슈 댓글 요약 등록을 한 번에 수행한다.
- **동작**: 이슈 디렉토리는 삭제가 아니라 `archive/`로 이관하며 비운다.
  1. **완료 확인**: `issue-<번호>-plan.md`의 Task 체크박스를 확인한다.
     미완료 Task가 있으면 목록을 보여주고 계속 진행할지 질의한다 (중단·종료 케이스).
  2. **summary 갱신**: `issue-<번호>-summary.md` 상단의 다음 작업을 갱신한다.
     완료 시 `✅ 모든 작업이 완료되었습니다.`, 중단·종료 시 종료 사유를 한 줄로 기재한다.
  3. **이슈 댓글 질의**: summary의 Task별 수행 결과를 기반으로 작업내용 요약을 작성해 보여주고,
     GitHub 이슈에 댓글로 등록할지 질의한다. 승인 시에만 등록한다.
     거절하거나 GitHub 연동 수단(gh CLI 등)이 없으면 건너뛰고 다음 단계를 진행한다.
  4. **archive 이관**: `issue-<번호>/` 디렉토리를 `active/`에서 `archive/`로 디렉토리 단위로 이동한다.
  5. **99_workspace 정리**: `.ai/99_workspace/` 하위 파일 목록을 보여주고(`.gitkeep`은 항상 보존),
     보존할 파일은 `archive/issue-<번호>/`로 이동을 제안한다. 나머지는 삭제 확인 후 삭제한다.

  `active/`에 이슈 디렉토리가 여러 개면 1~4단계를 이슈별로 반복한 뒤 5단계를 1회 수행한다.

> `## 이슈 완료 시` 절차는 이 옵션의 1·2·4단계에 포함된다.
```

### 3. `## 이슈 완료 시` 섹션 끝에 추가

```markdown
> 위 절차에 더해 `99_workspace` 정리와 이슈 댓글 요약 등록까지 한 번에 수행하려면 `--clear` 옵션을 사용한다.
```
